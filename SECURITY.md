# Security Policy

## Reporting a vulnerability

If you find a security issue in Ghostid (the app, the API, or this repository), **do not open a public issue**.

Email **security@autokeren.com** with:

- A description of the issue
- Steps to reproduce
- The affected version (shown in the app)
- Your device + Android version

We will acknowledge within 72 hours and coordinate a fix + disclosure timeline with you.

## Scope

| Target | In scope |
|---|---|
| Ghostid Android app | Yes |
| REST + MCP API | Yes |
| Tunnel/auth handling | Yes |
| This repository (recipes, docs) | Yes |

## Out of scope

- Issues requiring root or a modified system image
- Social engineering
- Denial of service via the free tier quota (working as intended)

## Safe harbor

Good-faith research on your own device is welcome. We will not pursue legal action for responsible disclosure.
